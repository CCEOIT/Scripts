Surface Go 2 — Student Session Cleanup

Pathways Program  |  CenterState CEO  |  Run between every student session

What This Script Does

The script automatically clears the following from the previous student's session:

  • All browsing history, saved passwords, cookies, and signed-in accounts in Chrome and Edge
  • Everything in Documents, Downloads, Pictures, Videos, and Music
  • All files and shortcuts added to the Desktop
  • Any Microsoft account connected to the computer (OneDrive, Teams, Office)
  • Recently opened files list
  • All saved WiFi networks — reconnects to ON-RAMP - Pathways automatically
  • Chrome and Edge shortcuts are restored to the Desktop before reboot

How to Run the Cleanup

1
Open C:\Scripts in File Explorer

Navigate to This PC → Local Disk (C:) → Scripts. You will see LaunchStudentCleanup and StudentCleanup listed here.

2
Right-click LaunchStudentCleanup and select "Run as administrator"

Right-click the LaunchStudentCleanup batch file and choose Run as administrator from the menu. If a UAC prompt appears, click Yes.

3
Press any key to start the cleanup

A black command window will open confirming what the script will do. Press any key to begin. Do not close the window while it is running.

4
Wait for it to finish and reboot

The script runs automatically. When complete it will display "Pathways Surface Wipe Complete" and restart the computer after 15 seconds. The machine is then ready for the next student.

Note: Logs from each run are saved to C:\Scripts with a timestamp in the filename. If something looks wrong after cleanup, open the most recent log file for details.
