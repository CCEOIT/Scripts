Pathways Program — Between Session Computer Cleanup

Run this script after every student session to reset the computer for the next student.

This script automatically clears

  • All browsing history in Chrome & Edge
  • Saved passwords & cookies
  • Signed-in Google & Microsoft accounts
  • OneDrive, Teams & Office sign-ins
  • Documents, Downloads, Pictures & Videos
  • Everything added to the Desktop
  • Recently opened files
  • Reconnects to ON-RAMP - Pathways WiFi

How to run it — 3 easy steps

1
Open C:\Scripts in File Explorer
Click the folder icon on the taskbar, then navigate to This PC → Local Disk (C:) → Scripts. You will see LaunchStudentCleanup listed there.
File Explorer — This PC > Local Disk (C:) > Scripts
2
Right-click LaunchStudentCleanup → "Run as administrator"
Right-click the file and choose Run as administrator. If a pop-up asks "Do you want to allow this app to make changes?" click Yes.
Right-click menu on LaunchStudentCleanup
3
Press any key and wait
A black window will open. Press any key to start. Do not close the window. The script runs on its own — when it is done the computer will restart automatically.
Command Prompt — Student Cleanup running
✓
You are done!

The screen will show "Pathways Surface Wipe Complete" and the computer will restart on its own. It will be ready for the next student once it boots back up.
